# EduStream - Réseau Pédagogique

Une plateforme éducative mobile inspirée de TikTok, permettant aux professeurs et élèves de partager des contenus pédagogiques.

## 🎯 Fonctionnalités

- ✅ Authentification (Professeurs / Élèves)
- ✅ Feed vidéo avec scroll vertical
- ✅ Système de likes et commentaires
- ✅ Partage de contenu
- ✅ Interface responsive
- ✅ Design moderne avec Tailwind CSS

## 📱 Construction APK

Consultez [BUILD_GUIDE.md](BUILD_GUIDE.md) pour les instructions complètes de construction.

### Démarrage rapide

```bash
# Installer les dépendances
npm install

# Ajouter la plateforme Android
cordova platform add android

# Construire l'APK debug
cordova build android

# Exécuter sur un appareil
cordova run android
```

## 🛠️ Stack Technique

- **Framework UI** : Tailwind CSS
- **Icons** : Font Awesome 6
- **Mobile** : Apache Cordova
- **Plateforme** : Android 7.0+
